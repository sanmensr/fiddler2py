## 图片规范

1. **格式**: 推荐使用 PNG 格式，支持透明背景
2. **大小**: 单个图片文件不超过 500KB
3. **命名**: 使用小写字母和连字符，避免中文和特殊字符
4. **色彩**: 主色调建议使用粉色系 (#FF69B4, #FFB6C1, #DDA0DD)

## 临时解决方案

在没有实际图片文件的情况下，小程序会使用 emoji 表情符号作为临时图标：
- 🏠 代替首页图标
- 🐾 代替宠物图标
- 🔮 代替占卜图标
- 📚 代替历史记录图标

## 获取图片资源

你可以通过以下方式获取合适的图片：
1. 使用 AI 图片生成工具（如 Midjourney, DALL-E）
2. 从免费图标网站下载（如 Flaticon, Icons8）
3. 自己设计制作
4. 购买商业图片素材

记得确保使用的图片符合版权要求！
