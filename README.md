# 萌宠紫微占星小程序

一个基于微信小程序的宠物占星运势应用，为你的萌宠提供专业的紫微斗数占星服务。

## 🌟 功能特色

### 🏠 首页
- 精美的渐变背景设计
- 今日运势快速预览
- 宠物类型选择
- 用户信息展示

### 🐾 宠物档案
- 详细的宠物信息录入
- 支持头像上传
- 多种宠物类型选择
- 性格特征分析

### 🔮 运势占卜
- 多种占卜类型（今日/本周/本月/爱情/健康/财富）
- 精美的计算动画效果
- 详细的运势评分
- 幸运元素推荐
- 个性化建议

### 📚 历史记录
- 运势历史查看
- 智能筛选功能
- 数据统计分析
- 记录分享功能

## 🎨 设计特点

- **色彩主题**: 粉色系渐变设计，温馨可爱
- **动画效果**: 丰富的CSS动画和过渡效果
- **响应式**: 适配不同尺寸的手机屏幕
- **用户体验**: 直观的操作流程和友好的交互反馈

## 📱 技术栈

- **框架**: 微信小程序原生开发
- **样式**: WXSS + CSS3动画
- **数据存储**: 微信小程序本地存储
- **工具函数**: 自定义占星算法

## 🚀 快速开始

1. **下载微信开发者工具**
   - 访问 [微信开发者工具官网](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
   - 下载并安装最新版本

2. **导入项目**
   - 打开微信开发者工具
   - 选择"导入项目"
   - 选择项目目录
   - 填入测试 AppID 或使用测试号

3. **配置项目**
   - 修改 `project.config.json` 中的 `appid`
   - 根据需要调整项目配置

4. **运行项目**
   - 点击"编译"按钮
   - 在模拟器中预览效果

## 🎯 使用说明

1. **创建宠物档案**
   - 输入宠物基本信息
   - 选择宠物类型和性格
   - 上传宠物头像

2. **进行运势占卜**
   - 选择占卜类型
   - 观看计算动画
   - 查看详细结果

3. **查看历史记录**
   - 浏览过往占卜记录
   - 使用筛选功能
   - 分享有趣的结果

## 🌈 自定义配置

### 修改主题色彩
在 `app.wxss` 中修改 CSS 变量：
```css
:root {
  --primary-color: #FF69B4;
  --secondary-color: #FFB6C1;
  --accent-color: #DDA0DD;
}
```

### 添加新的占卜类型
在 `pages/fortune/fortune.js` 中的 `fortuneTypes` 数组添加新类型。

### 自定义占星算法
修改 `utils/astrology.js` 中的相关函数。
